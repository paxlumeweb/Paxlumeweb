# Paxlume Web Studio — website source

This is a static website portfolio containing three **fictional demonstrations**. It is ready to deploy to GitHub Pages. The business contact button opens an email message to the business inbox.

## Recommended repository
`paxlumeweb/Paxlumeweb` (the public repository you created; *not* the unrelated CTA game repository).

## Upload to GitHub
1. Sign into the GitHub account **paxlumeweb** and open <https://github.com/paxlumeweb/Paxlumeweb>.
2. Choose **Add file > Upload files** (or **uploading an existing file** if the repository is empty). Upload the *contents* of this package, with the demo directories preserved. Do not upload private customer documents or passwords.
3. Commit the files to the repository's default branch (`main`, if that's what GitHub uses for this repo).
4. Open **Settings > Pages**, set **Build and deployment > Source** to **Deploy from a branch**, choose `main`, `/ (root)`, then **Save**.
5. After GitHub confirms successful deployment, the expected project URL is <https://paxlumeweb.github.io/Paxlumeweb/>. It will not work until GitHub Pages is enabled and deployment succeeds.
6. Test the main portfolio, all three demo links and the email contact button on phone and desktop.

If using ChatGPT to upload instead of doing it manually, the connected GitHub account must be **paxlumeweb**, or another account with **write** permission to this repository. The previously connected **Jakeclur** account does not currently have that permission.
